## Habr (анонс; заголовок + тело)

**Заголовок:** mbSCADA v1.4.3 — Modbus Poll на чистом Rust: мастер, slave-симулятор и SCADA-режим в одном exe

**Тело:**

Это чистая (clean-room) реализация идей Modbus Poll — без чтения чужих исходников, — дополненная полноценным SCADA-слоем. Проект написан на Rust с фронтендом на ванильном JS (Tauri 2), собирается в один исполняемый файл ~6 МБ и распространяется по MIT.

### Что умеет v1.4.3

**Мастер.** Пять транспортов: Modbus TCP (MBAP), RTU over TCP (честный CRC16 поверх сокета), Serial RTU через физический COM/RS-485 (включая обработку эха двухпроводной линии), Serial ASCII и ASCII over TCP. Опросы настраиваются per-window: функция (01–04), адрес в любой нотации (raw / 4x0000 / 40001+ / с 1), количество, период от 20 мс, формат от uint16 до float64 с перестановками байтов и масштабированием (mult/div/offset).

**Slave-симулятор.** Приложение само отвечает как Modbus-устройство: TCP, RTU over TCP или физическая serial-линия с ресинком по тишине 300 мс. Регистры правятся кликом по сетке, есть автогенерация (синус/пила/шум) — мастер видит «живое устройство». Идеально, чтобы тестировать чужие мастера или свои опросы без стенда.

**SCADA-режим.** Дерево правил из 32 веток на строку (цвет текста/фона, мигание, уровни info/warning/critical, меняющийся текст), вычисляемые тэги с выражениями (`{T2 рубашка} - {T1 реактор}`), мимик-схемы с drag&drop (лампы, полосы, гейджи, кнопки записи), тренды-спарклайны в каждой строке, формат отображения каждой ячейки (dec → hex → bin по ПКМ).

**Данные.** Импорт настоящих файлов Modbus Poll (.mbp/.mbw) байт-в-бит: таблицы, псевдонимы строк, периоды, адреса. С v1.4.3 импортированные опросы следуют за Slave ID соединения — сменили адрес устройства в коннекшене, и все опросы подхватили его автоматически. CSV-история значений (по изменению или по периоду) и журнал обмена (RX/WR/ERR/SYS).

### Что нового в 1.4.x

- **1.4.0** — slave-симулятор по физической serial-линии (COM/RS-485);
- **1.4.1–1.4.2** — запись значений переживает разрывы линии, slave корректно стартует на занятых портах, обработано эко RS-485;
- **1.4.3** — импорт .mbp/.mbw: опросы следуют Slave ID соединения (в т.ч. после обновления коннекшена), ошибки старта slave показываются рядом с кнопкой, панель слейва переименована по-humanly: «Транспорт» вместо «Кадров», пошаговая подсказка запуска.

### Технические детали

Workspace из крейтов: `mb-proto` (фрейминг MBAP/RTU/ASCII + CRC16), `mb-format` (парсер .mbp/.mbw), `mb-engine` (движок опроса, правила, выражения, импорт), `mb-sim` (slave-симулятор). 68+ тестов в CI, сборка под 5 платформ: Windows (exe/msi), Linux (deb/rpm/AppImage, x64+arm64), macOS (dmg).
